{% hint style="info" %}
**Executive Summary**
Процесс импортозамещения в сегменте телекоммуникаций и ЦОД в РФ перешел из фазы концептуального проектирования в фазу **жесткого прагматизма ([TRL 7–9](../lib-1/TRL_Scale.md#trl-7-9))**. В условиях ограничений на доступ к передовым полупроводниковым фабам (TSMC, Samsung, Intel Foundry) стратегия «абсолютного технологического суверенитета» сменилась стратегией **управляемой переориентации на экосистему КНР**. 

Ключевым драйвером этой трансформации стали результаты китайской государственной программы **[«Made in China 2025» (MIC2025)](../lib-1/Made_in_China_2025.md)**. КНР создала независимые стеки в области литографии ([SMIC](../lib-1/SMIC.md)), упаковки ([JCET](../lib-1/JCET.md)), производства NAND ([YMTC](../lib-1/YMTC.md)), ARM/Loongson процессоров и оптических компонентов ([Accelink](../lib-1/Accelink.md), [Innolight](../lib-1/Innolight.md)). РФ экспортирует эту технологическую зависимость, локализуя китайские OEM/ODM-платформы под видом национальных продуктов для включения в Реестр Минпромторга.
{% endhint %}

## 1. Замещение Western-Legacy (Cisco/Ericsson/Nokia) на решения КНР и локализованные платформы

Массовый уход западных вендоров (Cisco, Ericsson, Nokia) потребовал каскадной перестройки телекоммуникационной инфраструктуры и сетевых фабрик ЦОД. Переход осуществляется по двухвекторной модели: прямая замена на решения Tier-1 КНР (Huawei, ZTE, H3C) и создание локализованных OEM/ODM-платформ «второго эшелона».

### Модель замещения корпоративных и телеком-сетей

```
 Western Legacy                   Промежуточный стек (Tier-1 КНР)             Локализованный стек (TRL 7-8)
┌─────────────────┐               ┌──────────────────────────────┐            ┌──────────────────────────────┐
│ Cisco Catalyst /│ ──(Замена)──> │ Huawei CloudEngine /         │ ──(OEM)──> │ Yadro / Aquarius / Fplus     │
│ Nexus           │               │ H3C S-Series                 │            │ (White-Label + FW Wrapping)  │
└─────────────────┘               └──────────────────────────────┘            └──────────────────────────────┘
┌─────────────────┐               ┌──────────────────────────────┐            ┌──────────────────────────────┐
│ Ericsson RBS /  │ ──(Замена)──> │ ZTE ZXSDR /                  │ ──(CKD)──> │ СП на базе Baicells / Comba  │
│ Nokia AirScale  │               │ Huawei BTS5900               │            │ (L2/L3 ПО РФ + L1 ASIC КНР)  │
└─────────────────┘               └──────────────────────────────┘            └────────────────└─────────────┘
```

#### Ключевые направления транзита:
1. **Сетевое оборудование ЦОД и Enterprise (Замена Cisco, Juniper, Arista):**
   * **Core Routing & Switching:** Магистральные маршрутизаторы Cisco ASR/NCS замещаются линейками **Huawei NetEngine** и **ZTE ZXR10**. В корпоративном сегменте коммутаторы Cisco Catalyst вытесняются продукцией **H3C** (серии S5130/S6520) и локализованными платформами от Yadro (серия Kornut) и Fplus.
   * **ПО и прошивки:** Для прохождения критериев локализации Минпромторга применяется процедура *Firmware Wrapping*. Она заключается в адаптации открытых сетевых операционных систем (NOS) на базе Linux/SONiC (Software for Open Networking in the Cloud) или установке отечественного ПО управления поверх аппаратных коммутационных матриц (ASIC) Broadcom/Marvell (импортируемых по каналам параллельного импорта) или китайских аналогов **Centec** (серии TsingMa/GoldenGate).

2. **Сети радиодоступа RAN (Замена Ericsson, Nokia):**
   * **Операторский уровень:** Прямые поставки от Huawei и ZTE ограничены рисками вторичных санкций для китайских гигантов. В связи с этим операторы «Большой Четверки» переходят на решения Tier-2 вендоров КНР (Baicells, Sunwave, Comba Telecom).
   * **Механика локализации:** Организация SKD/CKD сборки на мощностях предприятий РФ (Yadro/Fabrika1, Аквариус) с формальной русификацией стека управления (L2/L3 уровня 3GPP) при сохранении проприетарного L1-кода китайского разработчика.

{% hint style="warning" %}
**Риск архитектурного «Черного Ящика»**
При замене оборудования Ericsson/Nokia на китайские OEM-платформы, низкоуровневые алгоритмы L1/PHY (Signal Processing, Beamforming, FFT/IFFT), выполняемые на DSP и специализированных ASIC, остаются закрытыми для российских инженеров. При изменении спецификаций 3GPP (Release 17/18) российские вендоры полностью теряют автономность и зависят от графиков обновления upstream-разработчиков из КНР.
{% endhint %}

## 2. Базовые станции 4G/5G: Схема локализации и TRL

```
 [КНР OEM (напр. Baicells/Sunwave)] ──(SKD/CKD поставка)──> [РФ СП / Завод] 
                                                                  │
 [Реверс-инжиниринг / FW Russification] <────────────────────────┤
                                                                  ▼
 [БС 4G/5G TRL 8] ──(Тесты в сетях «Большой Четверки»)──> [Реестр Минпромторга]
```

### Технический статус и скрытые TRL-барьеры
* **TRL 7 (Демонстрация системы в операционной среде):** Отечественные разработки на базе архитектуры OpenRAN (Сколтех, Ядро) столкнулись с дефицитом высокопроизводительных ПЛИС (FPGA) Intel (Altera) Arria/Stratix и AMD (Xilinx) UltraScale+, необходимых для реализации блоков цифровой обработки сигналов (DFE - Digital Front End). См. также [сравнение аппаратных платформ](#сравнительный-технический-анализ-cpu-архитектур).
* **TRL 8–9 (Коммерческая система, прошедшая испытания):** Достигается **исключительно** за счет крупноузловой (SKD) и мелкоузловой (CKD) сборки решений китайских OEM-производителей «второго эшелона».

### Связь с программой «Made in China 2025»
Китайская программа [Made_in_China_2025](../lib-1/Made_in_China_2025.md) полностью закрыла потребности РФ в радиочастотных компонентах:
* **GaN/GaAs усилители мощности (Power Amplifiers):** Продукция китайских фабов (SICC, Sanan IC) полностью заменила компоненты Sumitomo и Qorvo.
* **MIMO-антенные массивы:** Использование элементов с технологией Beamforming от китайских поставщиков (Tongyu Communication).

## 3. Серверное оборудование: Сравнительный анализ архитектур

Локализация серверных систем идет по трем параллельным трекам:

```
                  ┌──> x86 (Hygon/Zhaoxin/Параллельный импорт) ──> TRL 8-9 (Legacy / Высокая зависимость)
                  │
Серверный стек ───┼──> ARM (Kunpeng/Phytium / *Baikal-S) ───────> TRL 7-8 (Проблемы с фабом TSMC)
                  │
                  └──> LoongArch (Loongson 3Q5000/3C6000) ──────> TRL 7 (Стратегический резерв КНР)
```

### Сравнительный технический анализ CPU-архитектур

| Параметр | x86 (Intel/AMD / Zhaoxin/Hygon) | ARM (Huawei Kunpeng / Phytium) | Loongson (LoongArch) |
| :--- | :--- | :--- | :--- |
| **Текущий TRL в РФ** | **TRL 8–9** | **TRL 7–8** | **TRL 6–7** |
| **Доступность литографии** | TSMC (Заблокировано), [SMIC](../lib-1/SMIC.md) 14nm (Zhaoxin) | [SMIC](../lib-1/SMIC.md) 7nm (Huawei/HiSilicon), SMIC 14nm | STC / [SMIC](../lib-1/SMIC.md) 12/14nm (Без IP ARM/x86) |
| **Программная экосистема** | Полная зрелость (x86-64) | Высокая (Linux, KVM, Docker, OpenGauss) | Средняя (Loongnix, Портирование Linux/QEMU) |
| **Уровень локализации** | Низкий (Параллельный импорт) / Средний (Zhaoxin) | Средний (Сборка плат в РФ, китайский кремний) | Высокий потенциал (Полная независимость от IP США) |
| **Производительность (SPECrate2017)** | Высокая | Высокая (Kunpeng 920 равен Xeon Gold) | Умеренная (3C5000 ~ Xeon Silver 4214) |

#### Глубокий анализ архитектурных особенностей:
1. **Hygon Dhyana (x86):** Процессоры созданы на базе архитектуры AMD Zen 1 в рамках совместного предприятия Chengdu Haiguang Microelectronics. Поскольку IP-ядро x86 лицензировано у AMD, производство жестко привязано к зарубежным фабам. Попытки переноса на [SMIC](../lib-1/SMIC.md) ограничены патентными спорами и санкционным давлением.
2. **Loongson (LoongArch):** 
   > [!info] Архитектура LoongArch (Loongson)
   > Архитектура LoongArch не требует лицензирования ARM или x86. Она содержит 1999 уникальных инструкций, включая расширения векторной обработки (LSX, LASX) и аппаратную трансляцию кода (MIPS, ARM, x86) — технологию LBT (Loongson Binary Translation). Применение в ЦОД (**TRL 7**) ограничено необходимостью пересборки стека ПО (ПО транслируется с потерей 15–30% производительности через LBT).

## 4. Edge Compute Deployment

Развертывание Edge Compute (периферийных вычислений) в РФ стало ключевым звеном для обеспечения устойчивости критической инфраструктуры, технологических процессов и финтех-операций на фоне деконнекта от централизованных облаков Западных провайдеров (AWS, Azure).

```
                      [Центральный ЦОД / Облако]
                                  │
                   (Оптические каналы 100G / WDM)
                                  │
                                  ▼
                     [Edge Compute Node (TRL 8)]
         ┌────────────────────────┼────────────────────────┐
         ▼                        ▼                        ▼
 [Prom-IoT / АСУ ТП]      [Телеком RAN (vRAN)]    [Финансовые шлюзы]
 (Loongson / Zhaoxin)     (ARM Kunpeng / FPGA)     (ПО Гост + SMIC ASIC)
```

### 4.1. Архитектура и Аппаратный Стек Edge-Узлов
* **Вычислительные модули:** Периферийные узлы строятся на базе компактных 1U/2U серверных платформ в защищенном исполнении (Industrial Edge). Используются процессоры **Loongson 3A5000/3B5000** и **Phytium D2000**, запаянные непосредственно на материнские платы BGA-способом на российских SMT-линиях.
* **Устойчивость каналов связи:** В качестве uplink-интерфейсов применяются дублированные резервные каналы на базе китайских 4G/5G-модемов (Quectel, Fibocom) с поддержкой двух SIM-карт российских операторов и аппаратных криптографических модулей (HSM) с поддержкой ГОСТ шифрования.

### 4.2. Сценарии применения Edge Compute
* **Локальный кэшинг и фильтрация трафика:** Вынос базовых функций BRAS (Broadband Remote Access Server) и DPI (Deep Packet Inspection) на периферию для снижения нагрузки на магистральную сеть.
* **Промышленные системы (АСУ ТП / IIoT):** Использование Edge-контроллеров под управлением ОС Real-Time Linux (Astra Linux Embedded / KasperskyOS) на базе архитектуры Loongson для управления технологическими процессами без обращения к центральному дата-центру.
* **Финансовые транзакции и микроплатежи:** Автономные Edge-узлы обеспечивают процессинг офлайн-платежей и гарантируют локальную валидацию транзакций при обрыве магистральных каналов. 

Для интеграции Edge-узлов с трансграничными платежными системами и устойчивыми финансовыми каналами используется инфраструктура, описанная в разделе [Cross Border IP & Fintech Payment Infrastructure](Cross_Border_IP_and_Fintech_Rails.md#payment-infrastructure).

## 5. Системы хранения данных (СХД) и Оптические трансиверы

### 5.1. Системы Хранения Данных (TRL 8–9)
Сегмент СХД в РФ разделен на два класса:
1. **Mid-range / Enterprise (SDS — Software Defined Storage):**
   * **ПО:** Отечественный стек (Yadro Tatlin, Baum, RAIDIX) поверх x86/ARM архитектуры.
   * **Аппаратные узкие места:** Переход на 3D NAND чипы компании **YMTC** (Yangtze Memory Technologies Corp).

{% hint style="info" %}
**Технология YMTC Xtacking (TRL 1-6 на уровне ячеек)**
Технология **Xtacking 3.0** от [YMTC](../lib-1/YMTC.md) разделяет производство периферийных цепей CMOS (декодеры адреса, усилители считывания) и самой матрицы ячеек 3D NAND на двух разных пластинах. Пластины соединяются методом гибридного медно-медного соединения (bonding) на молекулярном уровне. Это позволяет достичь плотности записи до 1 Tb на кристалл при 232 слоях. РФ полностью зависит от импорта этих чипов, так как отечественные полупроводниковые заводы не обладают технологиями трехмерного стекирования памяти.
{% endhint %}

2. **High-End СХД (ASIC-based):** TRL не превышает **6–7** при попытке создать собственные ASIC-контроллеры СХД. Рынок импортирует готовые массивы Huawei OceanStor под видом локализованных OEM-решений.

### 5.2. Оптические трансиверы (10G - 400G)

```
 [КНР: Инициаторы (InP/GaAs), WDM-фильтры]
                     │
                     ▼
 [РФ: Фотонная сборка (T8, Промсвязь)] ──(SMT + Микросварка)──> [Трансиверы 10G-400G TRL 8]
                     ▲
                     │
 [КНР/Тайвань: DSP-процессоры (Innolight/Accelink)]
```

{% hint style="danger" %}
**Критический физический барьер фотоники (TRL 1-3 в РФ)**
В РФ отсутствует промышленное производство лазерных диодов DFB (Distributed Feedback) и EML (Electro-absorption Modulated Lasers) на подложках фосфида индия (InP) и арсенида галлия (GaAs) для скоростей передачи данных >25 Gbps. 

Производство требует установок молекулярно-пучковой эпитаксии (MBE) или газофазной эпитаксии из металлоорганических соединений (MOCVD), которые находятся под жестким экспортным контролем. 100% компонентов optical engine (TOSA/ROSA) и DSP-процессоры импортируются из КНР ([Accelink](../lib-1/Accelink.md), [Innolight](../lib-1/Innolight.md)). Сборка в РФ ограничивается корпусированием и пайкой на плату (Packaging), выполняемой на мощностях [JCET](../lib-1/JCET.md) или локальных сборочных линиях.
{% endhint %}

| **Оптические трансиверы**| **7–8** | **Критическая** (TOSA/ROSA матрицы, InP диоды, DSP) | **Высокий** (Сборка в РФ — это лишь packaging) | Отсутствие чистых комнат класса ISO 3–5 для фотоники и установок эпитаксии для InP/GaAs. |

## 7. Интерактивный кейс самопроверки

{% hint style="info" %}
**Практический сценарий для архитекторов**
**Условие:** Вы проектируете отказоустойчивый периферийный дата-центр ([Edge Compute Node](#4-edge-compute-deployment)) для регионального банковского узла. Требуется соответствие требованиям Реестра Минпромторга, высокий уровень TRL (не ниже 8) и устойчивость к потенциальным санкционным блокировкам Western IP.

**Какую процессорную архитектуру и модель локализации аппаратного стека вы выберете?**

* **Вариант А:** Серверы x86 (Intel Xeon) по параллельному импорту.
* **Вариант B:** Серверы на базе Loongson 3C5000 (LoongArch) с бинарной трансляцией LBT.
* **Вариант C:** Серверы локальной SMT-сборки на базе архитектуры ARM (Kunpeng / Phytium) с ПО SDS на базе Linux и чипами YMTC.
{% endhint %}

`─── СВЕРНУТЬ / РАЗВЕРНУТЬ ОТВЕТ ───`

{% hint style="success" %}
**Разбор вариантов**
* **Неверно (Вариант А):** Риск внезапной блокировки обновлений микрокода (Intel ME), невозможность легального включения в Реестр Минпромторга (не соответствует критериям локализации по 719-му Постановлению РФ), высокие риски пресечения каналов серого импорта.
* **Частично верно (Вариант B):** Достигает максимального суверенитета от IP США, но снижает производительность на 15-30% из-за LBT, а текущий TRL в РФ равен 6-7, что не соответствует условию задачи (требуется TRL не ниже 8).
* **ПРАВИЛЬНО (Вариант C):** Вариант C обеспечивает оптимальный баланс. Архитектура ARM имеет высокую готовность ПО (TRL 8), плата собирается на заводах в РФ (SMT-монтаж), память поставляется через YMTC (MIC2025), а для транзакций используется связка с [платежной инфраструктурой](Cross_Border_IP_and_Fintech_Rails.md#payment-infrastructure).
{% endhint %}
