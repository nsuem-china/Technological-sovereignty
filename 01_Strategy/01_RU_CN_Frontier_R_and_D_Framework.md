{% hint style="info" %}
**Стратегическое резюме**
Настоящий документ задает институциональную, нормативно-правовую и инженерно-управленческую архитектуру совместных научно-исследовательских проектов Российской Федерации и Китайской Народной Республики на фундаментальных стадиях (**TRL 1–3**). Главная цель концепции — исключить превращение отечественного академического сектора в «сырьевой прилавок фундаментальных идей» для китайского индустриального конвейера ([Made in China 2025](../Made%20in%20China%202025.md)) за счет внедрения строгой модели защиты **IP**, аудита предшествующих технологий (**Background IP (BIP)**), паритетного использования установок **Mega-Science** и суверенного контроля за трансграничным обменом данными.
{% endhint %}

## 1. Институциональная асимметрия и синхронизация (TRL 1–3)

Сотрудничество между научным контуром РФ (**РАН**, **Минобрнауки**, **НИЦ «Курчатовский Институт»**) и государственными структурами КНР (**CAS**, **MOST**, **NSFC**) строится на компенсации структурных дисбалансов национальной инновационной системы каждого из государств.

```
  [ РФ: РАН / Минобрнауки / Курчатовский Институт ]
      ┌──────────────────────────────────────────┐
      │  TRL 1 - TRL 3: Фундаментальный задел    │  - Теоретическая физика и математика
      │  (Высокая фундаментальная глубина)       │  - Квантовая оптика, материаловедение
      └────────────────────┬─────────────────────┘  - Сильнокоррелированные системы
                           │
                           ▼ (Переход через «Долину смерти» TRL 3->4)
      ┌──────────────────────────────────────────┐
      │   Совместный регулируемый контур R&D     │ ◄── [ Escrow-депонирование / Crypto-audit ]
      └────────────────────┬─────────────────────┘
                           │
                           ▼ (Промышленное масштабирование)
      ┌──────────────────────────────────────────┐
      │  TRL 4 - TRL 6+: Инженерный конвейер     │  - Литейные мощности (Foundries)
      │  (Массовое производство и выведение)    │  - Коммерциализация на рынках **БРИКС+**
      └──────────────────────────────────────────┘
  [ КНР: CAS / MOST / Промышленный сектор (MIC2025) ]
```

### Матрица институциональной синхронизации и Stage-Gates (TRL 1–3)

Разработка на ранних этапах требует строгого разделения зон ответственности и контрольных точек (Gatekeeper Metrics):

| Уровень готовности | Технический результат | РФ Институты (**РАН** / **РНФ**) | КНР Институты (**CAS** / **NSFC**) | Критерий прохождения (Gate Check) |
| :--- | :--- | :--- | :--- | :--- |
| **TRL 1** (Basic Principles) | Математическая модель, фундаментальное явление | Фундаментальная теория, физические концепты, кристаллография | Вычислительный скрининг, симуляции на суперкомпьютерах | Подача заявки на фиксацию **Background IP (BIP)** в цифровом реестре |
| **TRL 2** (Technology Concept) | Аналитическая модель, цифровой двойник | Моделирование взаимодействия, формулы материалов | Разработка микрофлюидных/эпитаксиальных техпроцессов | Совместная публикация **только** после закрепления **Prior Art** |
| **TRL 3** (Proof of Concept) | Лабораторный стенд, измеримый эффект | Экспериментальная верификация на установках **Mega-Science** | Прецизионное прототипирование, синтез образцов | Получение лицензий экспортного контроля (**ФСТЭК** / **MOFCOM**) |

{% hint style="info" %}
**Асимметрия инновационного цикла**
Если РФ исторически лидирует в генерации фундаментальных физико-математических идей (**TRL 1–2**), то КНР обладает феноменальной скоростью разворачивания лабораторных PoC (Proof of Concept) в инженерные образцы (**TRL 3–4**). Без жесткого контроля этапа TRL 3 интеллектуальная маржа полностью переходит к стороне, обладающей промышленной инфраструктурой.
{% endhint %}

## 2. Нормативно-правовой контур и трансграничный экспортный контроль

Переход проекта от фундаментальной теории к лабораторному образцу регулируется жесткими барьерами экспортного контроля и защиты национальной безопасности.

```
  [ TRL 1: Теория ]  ──► Cryptographic Hashing of BIP (Хэширование в Блокчейн)
            │
  [ TRL 2: Модель ]  ──► Подача совместной PCT-заявки + Защита приоритета в **CNIPA** / Роспатенте
            │
  [ TRL 3: PoC ]     ──► Двусторонний экспортный контроль (**ФСТЭК** / **MOFCOM**) + CBDT Gate
```

{% hint style="warning" %}
**Регуляторный барьер трансферта данных (CBDT)**
Передача массивных наборов данных (Big Scientific Data), полученных в ходе работ TRL 2–3 (например, результаты измерений на синкротронах или структуры материалов), подпадает под двойные ограничения:
* **Законодательство РФ:** Закон N 183-ФЗ «Об экспортном контроле» и нормативы **ФСТЭК** / **ФСБ** по защите сведений двойного назначения.
* **Законодательство КНР:** Закон о безопасности данных (*Data Security Law*, DSL) и Закон о кибербезопасности (*CSL*), квалифицирующие исходные научные данные как «важные данные» (*Important Data*), запрещенные к вывозу без оценки Поискового бюро киберпространства КНР (**CAC**).
{% endhint %}

### Ключевые институциональные механизмы:

1. **Двухуровневый экспортный аудит:**
   * ****ФСТЭК** (РФ):** Экспертиза научных результатов на предмет возможного создания оружия массового поражения или ракетных технологий двойного применения до передачи исходных файлов партнеру.
   * ****MOFCOM** (КНР):** Лицензирование передачи базовых технологий в сфере редких металлов, эпитаксии и оборудования для производства микроэлектроники.
2. **Смарт-Депонирование via **Escrow-агенты**:**
   * Передача точных технологических карт, CAD-моделей микроструктур и исходных кодов квантовых алгоритмов производится исключительно через депонирование у юридически независимого Escrow-агента.
   * Доступ к технологическому пакету для перехода к TRL 4 подписывается сторонами только при условии выполнения финансовых обязательств по соглашению о паритетном разделении будущей выручки.
3. **Фиксация **Prior Art** (Уровень техники):**
   * Введение моратория на любые научные публикации (включая журналы *Nature*, *Science*, *Спектроскопия*) сроком от 90 до 180 дней с момента получения физического эффекта (TRL 3) для подачи национальной патентной заявки.

## 3. Архитектура защиты и разделения IP (Intellectual Property)

Главная уязвимость российских научно-исследовательских групп на стадиях TRL 1–3 — склонность к публикационной активности в ущерб правовой защите, что делает их жертвами схемы ****Patent Flooding**** (патентное затапливание).

{% hint style="danger" %}
**Механика атаки Patent Flooding**
Получив в ходе совместного семинара или промежуточного отчета формулу перспективного соединительного материала (TRL 2), китайская сторона может сгенерировать кустовую патентную сеть из 50–100 патентов через Патентное ведомство КНР (**CNIPA**), охватывающих минимальные технологические допуски, методы спекания и варианты применения. В результате первоначальный автор фундаментальной идеи лишается права производить продукцию на TRL 4–6 без покупки лицензии у партнера.
{% endhint %}

```
                               ┌─────────────────────────────┐
                               │   Результаты R&D (TRL 1-3)  │
                               └──────────────┬──────────────┘
                                              │
                      ┌───────────────────────┴───────────────────────┐
                      ▼                                               ▼
        ┌───────────────────────────┐                   ┌───────────────────────────┐
        │  Background IP (BIP)      │                   │  Foreground IP (FIP)      │
        │  100% Монопольная         │                   │  Совместная собственность │
        │  собственность автора     │                   │  (Паритетный режим)       │
        └───────────────────────────┘                   └─────────────┬─────────────┘
                                                                      │
                                              ┌───────────────────────┴───────────────────────┐
                                              ▼                                               ▼
                                ┌───────────────────────────┐                   ┌───────────────────────────┐
                                │ Территориальное деление   │                   │ Oтраслевое деление        │
                                │ - РФ/СНГ: Эксклюзив РФ    │                   │ - Космос/Атом/ОПК: РФ     │
                                │ - КНР/АТР: Эксклюзив КНР  │                   │ - Consumer Tech/Auto: КНР │
                                └───────────────────────────┘                   └───────────────────────────┘
```

### Модель распределения прав на интеллектуальную собственность:

1. **Строгая сегрегация BIP и FIP:**
   * ****Background IP (BIP)**:** Полный перечень патентов, алгоритмов и ноу-хау, созданных до начала joint-проекта. Подлежит обязательной инвентаризации, нотариальному депонированию и внесению в реестр. Включается в проект на условиях ограниченной, неисключительной, безвозмездной лицензии *только* для целей выполнения работ в рамках TRL 1–3.
   * ****Foreground IP (FIP)**:** Оформляется исключительно как совместная собственность с обязательным указанием персонального состава авторов с обеих сторон. Подача заявок происходит по процедуре Договора о патентной кооперации (**PCT**) одновременно в Роспатент и **CNIPA**.

2. **Математическая модель распределения долей FIP:**
   Доля собственности ($S$) в конечном FIP на этапе перехода TRL 3 -> TRL 4 рассчитывается с учетом коэффициента фундаментального вклада ($\alpha$) и финансово-инфраструктурного вклада ($\beta$):

   $$S_{RU} = \alpha \cdot \left(\frac{I_{theory}}{I_{total}}\right) + \beta \cdot \left(\frac{C_{RU}}{C_{total}}\right)$$

   Где $I_{theory}$ — вес верифицированных теоретических модулей, $C$ — финансовые затраты на лабораторную базу.

3. **Двухмерная матрица разделения прав (Territorial & Field-of-Use):**
   * **Территория:** Российская сторона получает исключительное право на коммерциализацию FIP на территории РФ, ЕАЭС и стран СНГ. Китайская сторона — на территории КНР и стран АСЕАН. В странах ЕС и США коммерциализация разрешена только через создание совместного предприятия (**JV**) с долями 50/50.
   * **Отрасли (Field-of-Use):** РФ оставляет за собой исключительные права на применение FIP в секторах: оборонная промышленность, космическая техника, ядерная энергетика, тяжелое машиностроение. КНР получает права на использование в: гражданской микроэлектронике, бытовой технике, электромобилестроении, телекоммуникациях (5G/6G).

## 4. Инфраструктура Mega-Science и каналы передачи данных

Проведение исследований TRL 3 требует привлечения экспериментальных установок класса **Mega-Science** (синхротроны, нейтронные реакторы, коллайдеры, токамаки).

```
┌──────────────────────────────────────────────────────────────────────────────────┐
│                      Mega-Science Инфраструктурный Контур                        │
├──────────────────────────────────────┬───────────────────────────────────────────┤
│             Установки РФ             │               Установки КНР               │
│  (**NICA**, **СКИФ**, **ПИК**, **РИФ**)│  (**EAST**, **SHINE**, **CSNS**, **FAST**) │
└──────────────────┬───────────────────┴─────────────────────┬─────────────────────┘
                   │                                         │
                   ▼                                         ▼
   ┌────────────────────────────────────────────────────────────────────────────┐
   │ Запрещенный вывод в публичный интернет / Защищенный магистральный канал    │
   │ Cryptographic Dark Fiber | 100 Gbps | ГОСТ / SM4 Encryption Hardware       │
   └─────────────────────────────────────┬──────────────────────────────────────┘
                                         │
                                         ▼
   ┌────────────────────────────────────────────────────────────────────────────┐
   │ Двусторонний комитет распределения пучка (BTAC Governance)                 │
   │ Жесткие паритетные квоты: 40% РФ / 40% КНР / 20% Третьи страны (**БРИКС+**) │
   └────────────────────────────────────────────────────────────────────────────┘
```

### Протоколы работы комитета BTAC (Beam Time Allocation Committee):

1. **Сквозная система квотирования (Quotas & Reciprocity):**
   Допуск китайских исследователей к станциям синкротрона **СКИФ** или коллайдера **NICA** осуществляется **строго по принципу зеркального паритета**. За каждый час работы ученых КНР на российских объектах российские физики получают эквивалентное время (Beam Time) на установках уровня **SHINE** (Шанхайский рентгеновский лазер на свободных электронах) или **EAST** (Суперпроводящий токамак).
2. **Кибербезопасность и шифрование сигналов:**
   * Прямая передача сырых экспериментальных данных с детекторов осуществляется по выделенным волоконно-оптическим линиям (*Scientific Dark Fiber*).
   * Поток данных шифруется с использованием комбинированных аппаратных модулей HSM: алгоритмы **ГОСТ 34.12-2015 («Кузнечик»)** на российской стороне и **SM4** на китайской стороне.
   * Фильтры DPI (Deep Packet Inspection) адаптированы для исключения блокировок научных потоков со стороны Great Firewall (GFW КНР) и ТСПУ (РФ).

## 5. Расширенный кейс для самопроверки (Decision Tree)

{% hint style="info" %}
**Ситуационный сценарий (Case Study)**
**Контекст:** Российский НИИ в рамках проекта TRL 2 сформулировал математическую модель и синтезировал кристаллическую структуру нового топологического изолятора для квантовых вычислителей. Передать образец для подтверждения эффекта (TRL 3) просит лаборатория **CAS** в Шэньчжэне. При этом китайский партнер выдвигает условия:
1. Передать не только сам образец, но и полную спецификацию химико-термического процесса синтеза.
2. Провести тесты на китайском синкротроне **CSNS** без включения представителей РФ в состав авторов замеров, ссылаясь на закрытый режим китайской лаборатории.
3. Оплатить 100% затрат на логистику за счет средств гранта **РНФ**.

**Задание:** Определите алгоритм действий руководителя проекта от РФ для защиты технологического суверенитета и соблюдения нормативной базы.
{% endhint %}

```

                                          │
        ┌─────────────────────────────────┼─────────────────────────────────┐
        ▼                                 ▼                                 ▼
```

### Правильный ответ: **Решение В (Специфический протокол защищенного трансфера)**

#### Пошаговый алгоритм реализации Решения В:

1. **Юридическая фиксация (TRL 2 Barrier):**
   * Внести технологическую спецификацию синтеза в реестр ****Background IP (BIP)**** института со снятием цифрового слепка (хэша) и нотариальным депонированием.
   * Подать заявку на совместный патент по системе ****PCT**** с указанием приоритета РФ, зафиксировав авторский коллектив (включая российских ученых).

2. **Прохождение экспортного контроля (Export Compliance):**
   * Направить физико-химические характеристики топологического изолятора на экспертизу в ****ФСТЭК**** для получения разрешения на временный вывоз образца (без передачи технологии производства).

3. **Управление инфраструктурным доступом (Mega-Science Audit):**
   * Выдвинуть встречное требование в комитет **BTAC**: тесты на **CSNS** проводятся либо с личным/удаленным участием российской группы через защищенный VPN-канал, либо образцы исследуются на отечественной установке (****СКИФ**** / ****РИФ****) с зачетом времени китайской стороне по паритетной квоте.

4. **Финансово-логистический паритет:**
   * Расходы на транспортировку и страхование уникального образца делятся 50/50, либо полностью покрываются принимающей стороной в рамках софинансирования от ****NSFC****.

**Вывод:** Реализация Варианта А гарантированно привела бы к утрате прав на FIP через ****Patent Flooding**** и нарушению законодательства об экспортном контроле РФ. Вариант Б приводит к технологическому тупику и заморозке перспективной разработки на стадии TRL 2.
